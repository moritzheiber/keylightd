keylightd APT repository

Ubuntu 26.04 (resolute), amd64 and arm64.

Add the signing key and the source, then install:

curl -fsSL @@REPO_URL@@/keylightd.gpg | sudo tee /etc/apt/keyrings/keylightd.gpg > /dev/null
sudo curl -fsSL @@REPO_URL@@/keylightd.sources -o /etc/apt/sources.list.d/keylightd.sources
sudo apt update
sudo apt install keylightd

The desktop applet is packaged separately:

sudo apt install gnome-shell-extension-keylightd

Verification

The repository index is signed by the keylightd archive key.

Fingerprint: @@FINGERPRINT@@

Key files: keylightd.gpg (binary keyring), keylightd.asc (ASCII).
